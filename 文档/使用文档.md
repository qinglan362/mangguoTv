# 自动化舆情收集平台 · 使用文档

> 适用版本：v1.0（一期）　更新时间：2026-08-18
> 本文档面向运营、品牌公关等业务用户，介绍平台的功能与操作方法。系统内部标识「芒果TV舆情监测」。

---

## 一、系统简介

自动化舆情收集与分析平台围绕「主题配置、定时采集、数据处理、舆情分析、异常预警、结果导出」提供一站式舆情监测能力。

一期支持 **小红书、微博**（真实采集，扫码登录）与 **模拟数据源**（演示/测试）。用户创建舆情主题（例如「芒果TV」「乘风2026」「咸鱼飞升」或具体明星姓名），配置关键词、排除词、采集平台、采集频率和监测周期，系统即自动持续采集相关公开帖子与互动数据，并通过去重、分类、情感识别和热度计算，形成结构化数据和可视化分析结果。

**核心能力一览：**

| 功能 | 说明 |
|---|---|
| 主题管理 | 创建/编辑/暂停/删除监测主题，配置关键词与采集规则 |
| 自动化采集 | 按设定频率定时采集，支持模拟数据与真实平台（扫码） |
| 数据清洗去重 | 自动过滤广告/垃圾内容，精确+相似双重去重 |
| 舆情分析 | 情感识别（正/中/负）、相关度、热度计算、观点与实体提取 |
| 异常预警 | 6 类预警规则，命中后站内/邮件通知 |
| 报告与导出 | 自动生成日报/周报，数据导出 CSV |

## 二、登录系统

1. 打开浏览器访问平台地址（开发环境为 `http://localhost:5173`）。
2. 输入管理员分配的 **用户名** 和 **密码**，点击「登录」。
3. 登录成功后默认进入「分析看板」；会话有效期内无需重复登录，token 过期后系统会自动刷新，刷新失败则需重新登录。

> 登录连续失败会被限流，请稍后再试。忘记密码请联系管理员在「用户管理」中重置。

### 角色与权限

| 角色 | 权限 |
|---|---|
| 管理员（红色标签） | 全部功能，含用户管理、系统设置 |
| 运营（绿色标签） | 主题、看板、帖子、预警、报告等业务功能，不含用户管理和系统设置 |

## 四、主题管理

主题是舆情监测的基本单位。每个主题对应一个监测对象（品牌、剧集、艺人等）。

### 4.1 新建主题

1. 进入「主题管理」→ 点击 **新建主题**。
2. 填写配置：

   **基本信息**
   - **主题名称**：必填，如「芒果TV」「乘风2026」。
   - **采集平台**：可多选，小红书、微博（真实采集，需扫码）或模拟数据。
   - **采集频率**：5~1440 分钟（步长 5），即系统按此间隔自动采集。建议 ≥30 分钟以避免被平台限流。

   **监控周期**
   - 监测开始/结束时间：可留空表示长期监测。

   **关键词**
   - **核心关键词**：剧名、演员名、角色名、节目嘉宾名等（必填至少 1 个）。
   - **关联关键词**：简称、别名、话题词、常见错别字等。
   - **排除关键词**：用于过滤同名人物、无关商品等干扰内容。

   > 输入关键词后按 **回车** 或点击 **添加** 加入列表，可随时删除。关键词命中任一即纳入该主题。

3. 点击 **保存**，主题即生效并开始按频率自动采集。

> 若选择的真实平台采集器未启用，页面会提示该平台将走「扫码采集」（MediaCrawler）。

### 4.2 编辑主题

在「主题管理」列表点击行内 **编辑**，可修改名称、平台、频率、监控周期与关键词（关键词为全量替换）。

### 4.3 暂停 / 恢复

- **暂停**：停止该主题的定时采集任务，已采集数据保留。
- **恢复**：重新开始定时采集。

### 4.4 立即采集

点击列表行内 **立即采集**：

- **模拟平台（mock）**：同步执行一次采集，页面返回各平台运行结果。
- **真实平台（小红书/微博）**：跳转 MediaCrawler 采集流程，浏览器弹出登录二维码，**扫码登录后自动按主题关键词抓取帖子和评论**，结束后自动导入平台。主题状态会显示红色「爬取中」标签，点击可进入详情查看进度/日志、停止或手动导入。

> 「爬取中」状态下系统不会重复发起新的采集任务，避免堆积。

### 4.5 删除主题

点击 **删除**，二次确认后删除该主题及关联帖子（**不可恢复**，请谨慎操作）。

### 4.6 主题详情

点击主题名称进入详情页，包含四个区域：

- **概览**：帖子总量、今日新增、负面帖数、待处理预警；情感占比环形图、平台分布环形图、最近运行表格。
- **帖子**：该主题按热度倒序的前 10 条帖子，点击进入帖子详情。
- **运行记录**：每次采集的运行明细（状态、触发方式、采集/新增/重复数量、重试、错误信息、时间）。
- **MediaCrawler 采集**（真实平台）：开始采集、停止、仅导入已有数据，并展示运行状态、日志与抓取计数。

## 五、分析看板

「分析看板」提供全平台（可切换主题、平台）的舆情总览：

| 板块 | 内容 |
|---|---|
| 概览卡片 | 帖子数量、今日新增、负面帖数、待处理预警 |
| 互动量趋势 | 点赞/评论/转发/收藏的堆叠面积图（按小时） |
| 舆情热度变化趋势 | 热度折线图 |
| 高频关键词 | 词云（最近 7 天，由 AI 精选） |
| 热门帖子 / 负面帖子 | 两个排行表格，点击行进入帖子详情 |

> 词云由 AI 生成耗时较长，该板块独立加载，不阻塞其他图表。看板按全量数据统计，不支持时间范围筛选。

## 六、帖子列表与人工修正

### 6.1 帖子列表

进入「帖子列表」，可按 **主题、平台、情感**（正面/中性/负面）、**排序**（最新发布/热度最高/点赞最多）与 **内容关键词** 筛选。表格展示内容、作者、平台、情感标签、点赞、评论、热度与发布时间。

- 点击内容进入帖子详情。
- 「查看原帖」跳转至平台原始页面。

### 6.2 帖子详情

详情页包含：

- **正文**：标题、内容、话题标签（#xx）、查看原帖按钮。
- **作者信息**：姓名、粉丝数、重点账号标记。
- **互动数据**：点赞/评论/转发/收藏。
- **关联主题**：命中的主题及匹配关键词。
- **舆情分析结果**：情感（含来源：规则/大模型/人工）、相关度、热度、识别实体、核心观点。
- **互动历史**：点赞快照趋势折线图。
- **平台评论**：通过爬虫抓取的评论列表（按点赞排序）。

### 6.3 人工修正

当 AI 分析结果不准确（如高风险的负面内容被判错）时，可进行人工修正：

1. 在分析结果卡片选择 **修正字段**：情感倾向 / 相关性 / 核心观点 / 关键实体。
2. 按字段类型填写修正内容与说明。
3. 提交后修正结果会写回分析结果，**并用于后续规则与模型优化**。

> 仅已分析（有大模型/规则结果）的帖子可修正；未分析帖子会提示。

## 七、预警中心

预警中心分三个 Tab：**预警事件、预警规则、通知记录**。

### 7.1 预警事件

- 按 **主题、状态、等级** 筛选。
- 点击行可展开查看**触发原因**、**相关帖子**（最多 10 条，带原帖链接）。
- 处理动作：
  - **确认**：标记事件为已确认（new → acknowledged），表示已关注。
  - **解决**：标记为已解决。

### 7.2 预警规则

点击 **新建规则** 配置预警，规则包含：

| 配置项 | 说明 |
|---|---|
| 名称 | 规则名称 |
| 主题 | 作用于哪个监测主题 |
| 规则类型 | 6 种（见下表） |
| 等级 | 低/中/高/紧急（影响建议关注度） |
| 启用开关 | 是否启用 |
| 通知渠道 | 站内 / 邮件 |
| 邮件接收人 | 逗号分隔的邮箱列表 |
| 冷却时间（分钟） | 同一规则触发后的最短间隔，防止重复轰炸（默认 60 分钟） |

**6 种规则类型：**

| 规则类型 | 触发条件 | 典型配置 |
|---|---|---|
| 负面关键词 | 帖子文本出现指定负面关键词，累计达最低条数 | 关键词列表、最少命中条数 |
| 点赞超阈值 | 负面帖点赞数超过设定值 | 点赞阈值（默认 1000） |
| 负面激增 | 单位时间内负面帖数量相对前段明显增长 | 窗口分钟、增长倍数、最少条数 |
| 同观点集中发布 | 同一关键词/观点在窗口内由多个账号集中发布（疑似水军） | 窗口、最少帖数、最少账号数 |
| 互动异常增长 | 单帖互动量短时间内快速增长 | 增长倍数、最少增量 |
| 重点账号负面 | 被标记为重点账号的账号发布负面内容 | 无需额外配置 |

> 规则创建/编辑后，系统会自动对**近 24 小时数据**做一次回溯检查，命中即产生事件。
> **无规则时不会产生预警事件**，顶部有提示条。

### 7.3 通知记录

查看每次通知的渠道（站内/邮件）、接收方、状态（已发送/失败/待发送）、时间与错误信息。邮件发送失败会自动回退为站内通知。

## 八、报告与导出

「报告与导出」分两个 Tab：**舆情报告**、**数据导出**。

### 8.1 舆情报告

- 按 **主题、报告类型（日报/周报）** 筛选。
- 点击 **生成日报 / 生成周报** 手动生成（也可由调度器每日 9:00 / 每周一 9:05 自动生成）。
- 报告表展示标题、主题、类型、日期、状态、生成时间。
- **查看**：弹出报告摘要（含统计网格）。
- **导出**：将报告数据导出为 CSV 文件下载。

> 报告摘要由大模型生成（包含舆情概述、负面分析、处置建议等）；未配置大模型时自动使用模板摘要，平台功能不受影响。

### 8.2 数据导出

- 按 **主题、情感** 筛选。
- 选择导出类型：
  - **帖子数据（post）**：平台、标题、内容、链接、作者、发布时间、互动数、情感、热度。
  - **全量数据（full）**：帖子数据 + 关联主题、匹配关键词、核心观点。
- 点击 **导出** 创建导出任务，任务完成后点击 **下载** 保存 CSV（UTF-8 编码，Excel 可直接打开）。

## 十、系统设置（管理员）

> 仅管理员可见此菜单。

「系统设置」展示调度器运行状态：

- **调度器状态**：运行中/已停止、派发线程状态。
- **调度任务列表**：任务名称、关联主题、触发器（「每 N 分钟」/「每天 HH:mm」）、上次执行时间与状态、下次执行时间。

## 十一、常见问题（FAQ）

**Q1：为什么「立即采集」真实平台时弹出二维码？**
真实平台（小红书/微博）需要通过浏览器扫码登录后由 MediaCrawler 抓取，登录态会缓存，下次采集无需重复扫码（过期后重新扫码）。

**Q2：采集频率设多长合适？**
需求建议 10 分钟至 1 小时。频繁采集可能触发平台限流，建议常规主题 ≥30 分钟，重点事件期间可临时调整为 10 分钟。

**Q3：为什么看板/帖子里没有数据？**
- 主题处于「已暂停」或不在监测周期内不会采集；
- 模拟数据源每天按小时生成，真实平台需完成扫码采集；
- 检查主题是否命中关键词、是否被排除词/排除用户过滤。

**Q4：情感分析准确吗？可以纠正吗？**
平台采用「规则层 + 大模型」双重识别，大模型未配置时自动降级规则层。对误判内容可在帖子详情进行**人工修正**，修正结果会反哺后续分析。

**Q5：为什么没有收到预警邮件？**
- 确认邮件渠道已开启（`DJANGO_EMAIL_ENABLED=1`）且规则配置了邮件接收人；
- 查看「通知记录」中的发送状态与错误信息；
- 邮件失败会自动回退为站内通知，可在「预警事件」中查看。

**Q6：重复帖子会不会重复统计？**
不会。系统按内容哈希与平台帖子 ID 双重去重，同一帖子命中多个关键词仅保留一条原始数据，并记录全部命中的关键词与主题。

**Q7：删除主题后数据还能找回吗？**
不能。删除主题会连带删除关联帖子，请谨慎操作。

## 十二、数据字段说明（常见）

| 字段 | 说明 |
|---|---|
| 情感 | 正面 / 中性 / 负面 / 未知 |
| 热度分 | 0~100，综合点赞、评论、转发、收藏与时间衰减计算 |
| 重点账号 | 系统标记的高影响力账号（如官方账号、KOL），可触发重点账号负面预警 |
| 采集频率 | 主题自动采集的间隔（分钟） |
| 监测周期 | 主题生效的起止时间 |
